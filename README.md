# bonpli.fr

Site de présentation de Bonpli, la veille hebdomadaire des appels d'offres publics informatiques (source : BOAMP, Licence Ouverte 2.0).

Une seule page statique (`index.html`), sans framework, sans script tiers, sans cookie, sans formulaire. Hébergée sur GitHub Pages.
